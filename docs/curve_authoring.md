# 曲线切线与批量编辑

R5 首个增量：关键帧保留 Step / Linear / Smooth 原有行为，新增 Hermite 模式。
入、出切线使用“数值/秒”的独立斜率；依据相邻时间差缩放后求值，不以固定帧率采样。
参考本地 TiXL SplineInterpolator 的 Hermite 插值，来源和改动见
[来源记录](../provenance/curves.json)，无新增库或时钟。

## 编辑方式

在属性面板或时间线选择曲线：点击并拖动图中关键帧可移动时间和值；Ctrl 点击可
增加选择。选中 Hermite 关键帧后拖动黄色切线柄修改斜率，表格也可直接输入数值。
切线柄的时间位置固定在相邻区间的三分之一处；这是手动 Hermite 切线，尚非加权
Bezier 控制柄。端点以外保持端点值。拖动结束提交一次事务，可撤销/重做。

展开“批量编辑关键帧”，勾选表格或点击全选，设置时间/数值的平移、缩放和基点。
正时间缩放保持关键帧方向，斜率同步乘以数值缩放/时间缩放，因此整段形状保持。
点击应用才提交；越界、时间碰撞或非有限数值拒绝整次操作。操作完成清空选择。

最多 1024 个关键帧。列表按可见行绘制；密集图中的关键帧标记按像素间距抽样显示，
不减少数据或采样精度。选择超过 16 个关键帧时隐藏切线柄，仍可批量处理全部选择。
入/出切线字段始终占据相同行高，避免不同插值模式破坏列表裁剪。

## 保存与兼容

项目与运行包的 Curve.Keyframe 新增 in_slope / out_slope，插值枚举新增 Hermite。
旧曲线缺失斜率时为零，原有三种模式的结果不变。旧 Player 对未知插值枚举明确拒绝，
不会静默按线性播放。组件内部曲线复用相同值类型、编解码器和时间线编辑器。
预设 JSON 可指定 hermite 及两条斜率；恢复默认不依赖新增字段。
