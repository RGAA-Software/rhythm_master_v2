# Windows 系统声音输入检查

Windows 的系统声音输入采用 WASAPI shared-mode loopback，打开默认渲染端点并读取
其最终混音。采集线程只发布分析后的频段、响度和 BPM 快照；不保存 PCM，也不进入
图或渲染公共 API。

Studio 的“开始监听系统声音”会停止当前文件／模板配乐并启动回环采集。只有右侧
音频输入状态显示“正在监听系统声音”，且响度条／频谱在移动时，系统声音才会被
送给音频特征和频带节点。选择模板绑定配乐或本地文件会反向停止系统采集，以避免
两个输入源同时驱动同一图。

本机 `audio_capture_tests.exe` 于 2026-09-10 通过：默认输出端点完成三次打开、
采集有效特征、停止和最终启动析构，未持久化 PCM。该检查证明设备回环可用；它不
代替用户以实际音乐确认所选作品的音频调制强度。
