# FXAA 节点与作品验证

日期：2026-09-09。实现契约、源码复用和限制见 [抗锯齿](../antialiasing.md)。

Windows D3D11 与 USB Redmi K40S / Adreno 650 GLES 使用相同 shader 源码。
三种 32×32 斜边测试各产生 63 个平滑覆盖像素；零强度、均匀单像素源、
预乘约束、透明黑边、能量误差和非法参数检查通过。两端完整 GPU 执行回归通过。
两端 FXAA 图契约通过发布往返、接线限幅、静态缓存、横竖尺寸与释放检查；
Windows 既有颜色运行和程序契约同时通过。

## 实际音乐作品

共振拱廊的末端 0.35 半径模糊替换为 FXAA，仍为 156 条执行指令。
晴空悬音在显示转换之后添加 FXAA，变为 104 节点、141 连线。
宏、Cue 与 16 秒原始配乐保留，节点参数在 Studio 中可编辑。
