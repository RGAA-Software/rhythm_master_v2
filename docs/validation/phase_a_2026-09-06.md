# Phase A implementation and validation — 2026-09-06

Status: **in progress**. The portable core and Windows editing slice are real
buildable implementations. This report does not close Phase A, approve a release
dependency lock, or claim Windows product acceptance.

Scope update from the user: transparent windows/backbuffers and their click-through

The Studio render experiment uses fixed embedded bgfx shaders and a 640×360 final
output. A separate native Compute probe builds a new shader and validates GPU
pixels. Neither is the 1080p/4K performance workload. No FFmpeg, network, Godot or
old application modules were prematurely folded into the standalone renderer.

## Defects found and corrected

- ImGui annotated tag identity was compared with a commit identity; preparation
  now verifies the dereferenced commit and resumes interrupted copies safely.
- CMake 3.28 misdecoded the Chinese MSVC include prefix, preventing correct Ninja
  header dependency capture. The build wrapper measures and supplies the prefix.
- node-editor requires EndCreate/EndDelete even when Begin returns false. The
  adapter now closes both scopes and unattended assertion failures reach stderr.
- Initial docking produced a provisional tiny canvas and invalid auto-fit.
  Fitting now waits for stable usable dimensions; visible-node smoke assertions
  would catch the previous blank/tiny canvas regression.
- Framebuffer attachment destruction needed to precede texture destruction.
  RAII cleanup now enforces that order, including failed allocation paths.
- Runtime dirty signatures needed source node and texture generation identities,
  not only scalar versions, to detect rewiring and replaced resources.
- Viewer snapshots were initially unbudgeted, and stacked thumbnails were clipped
  by the panel. Scheduling and side-by-side thumbnails now have contract coverage.
- POSIX directory entries were not synced before CURRENT publication. Revision
  directories now sync before commit. Windows uses file flush and write-through
  replacement; identical power-loss semantics are not claimed without tests.
- A device-loss transition now makes stale handles unusable while still allowing
  their RAII owners to release backend allocations. Native injection tests then
  recreate the device on the existing SDL window and verify rendering resumes.
