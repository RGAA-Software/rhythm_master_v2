# R6 六个音乐效果层

接续 `fbf36db`，组件库从 11 项扩充至 17 项，新增 12 条默认/结构变奏预设记录。
原生预设仍为 132 条，总记录 166；完整作品仍为 40 个示例。
这些数量不等于独立视觉预设或基础 50 + 高级 50 的品质验收。

## 提取合同

复用六个现有第一方作者脚本的结构化记录，提取最终背景/后期合成之前的依赖闭包，
增加可编辑显示转换、5 个公开参数、结构变奏和内部布局。
参数分别按几何、图案、动态、材质/光照、相机/焦点分组；拒绝公开已经被连线驱动的同名参数。
保留内部节点 ID 和来源摘要，见 `provenance/semantic_layers_r6.json`。
没有新媒体后端、外部素材或第三方源码导入。六层均可继续编辑其内部网络。

## 功能与视觉证据

- 17 项组件的默认/变奏：插入、连接、撤销/重做、编解码、发布数据和 60 帧运行，
  Windows 与 Android 共享核心均通过。
- 六个默认层的 Android GLES 非黑画面及设备重建检查通过。
- Windows 对同一场景时间输入真实解码演示音乐、静音、低频和高频 PCM，
  每层四种比较均通过原有像素差阈值；所有比较期间纹理占用稳定。
- 真实 256×144 缩略图已生成，六层构图已查看：管线编织、花瓣、柱阵、球体纹理、
  粒子云和城景是不同的可复用图层。`out/r6-semantic-contact.png` 为检查拼图，
  这不是用户品质验收，也不把已有作品提取层计为新作品。

日志：`out/r6-semantic-music-tests.log`、`out/r6-semantic-android-tests.log`、
`out/r6-semantic-android-gpu.log`；每层音乐像素差在 `out/r6-semantic-music/*/pixel-differences.json`。

同档 420 帧检查。变奏的 p95 分别为 8.88、9.80、18.39、15.94、16.45、5.55 ms，

`out/r6-semantic-variant-gpu.log`、`out/r6-semantic-variant-android-gpu.log`。
