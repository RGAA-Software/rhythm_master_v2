# 瓷光钟摆功能交付

第一方基础作品候选，119 个可编辑节点、165 条连线，1280×720。
陶瓷外环、黄铜刻度和酒红钟摆组成浅色机械构图，包含地面投影、环境反射与景深。
复用现有几何、GPU 变形、灯光和合成节点，没有新增渲染器或外部素材。
来源和两个原始音频文件见 `provenance/porcelain_pendulum.json`。

低频控制摆幅与第一内环，中频驱动第二内环，高频改变外围珠子的大小。
三个公开宏控制音乐响应、机械节奏和曝光；三套快照、四条 Cue 构成 16 秒演出。
四条音频片段复用光幕协奏的原创 pulse/chime 配乐，可继续编辑或替换。

## 验证

- Windows 真实解码音乐、静音、80 Hz 和 3500 Hz 在相同 4 秒场景时间对照。
  平均 RGB 绝对差分别为完整音乐/静音 0.6569、低音/静音 1.4215、
  高音/静音 1.1361、低音/高音 2.5538；稳定纹理 43,059,396 B。
  初稿低音响应不足，已调整频段与摆幅，没有降低差异检查阈值。
- 通过实际 Studio 导出按钮输出 480 帧、16 秒 H.264 MP4，解码验证时间戳与非静音 PCM。
  导出期间编辑器继续绘制，主图保持 119 节点。该检查同时发现并修复了
  关闭目录预览占满线程池、阻止导出的集成问题，见 [浏览器生命周期](../catalog_authoring_plan.md)。
- USB Redmi K40S / Adreno 650 原生 GLES 非黑帧、设备重建和短测通过。
  Balanced 960×540，420 帧中的后 300 帧同步耗时 p50 12.56 ms、p95 15.95 ms，
  稳定纹理 25,318,596 B。这是离屏短测，不是热稳定或持续帧率保证。
- APK 使用 `adb install -r` 覆盖安装，直接从内置目录选择；配乐自动播放、总长 16 秒、
  非零 RMS、横屏画面和三个演出宏/Cue 显示已在手机实际检查。测试后回到桌面。
- 缩略图来自实际 Windows Player 渲染，记录运行包与像素摘要。
