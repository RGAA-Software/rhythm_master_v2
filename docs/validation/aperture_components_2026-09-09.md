# 螺旋与遮罩组件交付

三项第一方输入组件复用现有映射、形状、仿射、轮廓、遮罩和模糊节点，
每项一个必需纹理输入、六个公开控件、默认与结构变奏，支持编辑内部图。
不引入新第三方代码；来源继续记录在 `provenance/input_components.json`。

| 组件 | 内部 / 演示指令数 | 功能与变奏 |
| --- | --- | --- |
| 极坐标旋涡 / Polar vortex | 12 / 16 | 对称折叠后形成螺旋纵深，低频推进、高频反扭；变奏改为正幂次展开螺旋 |
| 音乐光阑 / Audio iris | 14 / 17 | 低频打开多边形孔径、高频旋转，保留透明区域；变奏为柔边三角镂空 |
| 亮度开窗 / Luma windows | 12 / 15 | 沿输入亮度切片开出透明窗口并保留源颜色；变奏为低密度、宽幅反向窗口 |

光阑 opening 范围 0.2–1.2，响应 0–2；慢速纹理 pace 为 ±0.25，
光阑角速度为 ±45。其他参数继承实际节点合法范围。
演示纹理只用于浏览，插入时不复制它们，作者连接自己的图像即可。

## 实画修正与验证

首轮螺旋演示仅横条纹，不随横向扭转变化；改成斜向输入后，真实高频响应可见。
随后实画检查发现极坐标角度接缝，组件内部加入四向对称折叠，使现有镜像采样下
接缝两侧一致。光阑演示条纹密度由 14 降为 6，便于观察孔径边缘；
原来的稀疏遮罩在 Android 16×16 缩略采样中未取得亮像素，未降低验证阈值。
Android 失败诊断现在分别报告像素可见性、GL 错误和峰值 pass，便于定位。
