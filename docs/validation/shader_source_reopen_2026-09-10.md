# Shader 源码恢复漏测与修复

日期：2026-09-10。涉及 Studio 的图像 Shader 编辑面板。

选择已有资产的节点，或者撤销／重做编译结果时，面板会构造仅含 Shader 节点的
临时图以异步读取源码。图编译器要求合法的 output.texture 输出节点，因此该图
一直被拒绝，文本缓冲被清空后仍被标记为加载完成。

旧 UI 测试在恢复后点击编译，只断言资产 ID 不变。空源码编译失败也会保留旧资产，
这个断言无法证明恢复成功。这属于以保留旧结果误判新操作成功的漏测。

新增回归直接聚焦源码输入框，读取 Dear ImGui 当前编辑状态，分别断言撤销与重做后
的完整表达式。未修复代码在 `out/p6-shader-reopen-reproduction.log` 实际失败，
提示源码与恢复资产不符；失败日志保留。

修复为临时图补齐独立输出节点与连线，避开所选节点 ID，使未连接到主输出的节点
也能读取源码。临时图构建失败时显示读取错误，不能静默清空错误状态。
`out/p6-shader-reopen-fix-tests.log` 的英文、中文 UI 回归和源码边界检查通过。

验证范围：实际编译工具、资产存取、历史撤销／重做和 ImGui 输入控件交互。
这是独立 ImGui 测试上下文，尚不替代后续可见 Studio 窗口的完整交付验收。
以后涉及 Shader 恢复的修改必须验证源码内容，不能只检查旧资产仍存在或画面仍显示。
