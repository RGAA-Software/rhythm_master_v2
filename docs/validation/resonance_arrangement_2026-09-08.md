# Four-section music arrangement example

**星门编排 / Resonance Arrangement** is an editable 16-second teaching arrangement
of the existing Resonance Live field and ring components. It is categorized as
a functional example, not an independent Basic/Advanced quality template. The
catalog now contains 31 runnable examples; the 50 + 50 quality goal remains open.

Twenty root nodes and 190 component-body nodes compile to 208 reachable
instructions. Four explicit `time.envelope` nodes use one looping `time.local`:

| Section | Interval | Fade in/out | Visual role |
| --- | --- | --- | --- |
| Opening | 0–5 s | 1.5 / 1 s | Large interlocking rings emerge |
| Buildup | 3–9 s | 1 / 1 s | Frequency field enters and rings recede |
| Climax | 8–13 s | 0.35 / 1 s | Spectrum, field and glow become dominant |
| Outro | 12–16 s | 1 / 2 s | Rings approach and field recedes |

Overlaps are intentional. Envelopes drive connected scalar expressions for layer
gain, ring scale and glow; actual music still drives the components' bands,
emission, particles and material parameters. Local section time repeats every
16 seconds; particle history and internal motion continue. This is not a
guarantee of a seamless particle loop or reconstruction after seeking.

Play the built-in demo music, select this example and open the timeline. Bars
edit the four envelope nodes; expand either component to inspect its primitives.
The root time-local duration is editable in its node inspector. Bind the music
before publishing to make the package self-contained. To stretch the arrangement
to another song, edit the time-local duration and section positions/durations.

## Reuse and visual corrections

`tools/author-resonance-arrangement.py` reuses the existing first-party graph
builder and embedded component authoring functions. Godot-derived torus geometry
and previously attributed effect adapters remain unchanged. No upstream source,
new dependency, codec, native host or hidden fixed-effect path was introduced.
Source records remain in `provenance/godot_3d.json` and the existing effect
records; this composition is project-owned and does not select an outbound license.

Initial phone captures showed insufficient visible music response in the tiny
opening rings. The arrangement now makes opening/outro geometry larger, and the
same pixel-response assertion passes. A second inspection found raster edge
magnification: the component now renders larger 3D geometry first and downsizes
the texture, instead of enlarging a small rasterized ring. The original Resonance
Live builder default remains unchanged.
