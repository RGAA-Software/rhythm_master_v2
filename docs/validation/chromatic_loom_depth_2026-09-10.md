# 织光机 0.3.0：构图与光梭轨迹修订

旧版偏正视角，较粗经纬遮住交错深度，光梭只呈现为两个点。
本次沿用已有图形算子和第一方创作脚本，改用斜向镜头、较细的 16 边管线，
并为两枚光梭各增加六个逐渐缩小的轨迹采样。轨迹共享已有球体网格和材质，
没有每帧重建网格、新增反馈纹理或引入第三方代码。原三频段完整覆盖、
三个公开宏、四段 Cue 与 16 秒原创合成配乐保留。

这是同一作品修订，不新增模板或独立预设数量。轨迹是当前音频幅度下的
延时解析路径采样，不声称保存历史音频状态的物理轨迹。

当前作者源摘要：`fe60332e2f45b835961de686f02a3419945f715a52a2c09194720abfbc2a9255`。
345 条可达指令、63 个频带、4 份管线网格。
