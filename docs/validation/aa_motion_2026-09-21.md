# 抗锯齿路径评估与细线/粒子对照验证（2026-09-21）

W1.5c：对照 Godot 4.5.1 的 MSAA/SMAA/TAA/FSR1/FSR2 路径（溯源
`provenance/aa_paths.json`）完成抗锯齿路线评估，并以 Windows D3D11
实测量化现行 FXAA 节点对运动细线与粒子的影响。

## 评估结论

保留按节点可选的 FXAA；不引入 TAA/FSR2（运动矢量依赖与刻意时域效果
冲突）、MSAA（只作用于几何边，作品锯齿主源是纹理链内容）、SMAA
（候选升级，当前无作品证明需要）；FSR1 是上采样性能手段，留 Android
性能阶段。完整对照表见 `docs/antialiasing.md`。

## 实际验证路径

- 新增永久回归 `windows_aa_motion_gpu`
  （`src/rhythm_render/tests/antialiasing_motion_gpu.cpp`，经
  `windows_gpu_execution_probe --aa-motion`）：
  64×64 目标，8 帧亚像素运动，逐帧 `RequestReadback` 实测：
  - 细线（1.5 px、斜率 0.1、0.25 px/帧）：plain 分数像素 0 → FXAA 108
    （阶梯摊平）；峰值 255 不变（线内有全亮核心）；逐像素帧间差
    1.53 → 1.73（时域闪烁未消除）。
  - 粒子（1.5 px 亮点对角漂移）：plain 能量 cv 0.48（覆盖闪烁剧烈）；
    FXAA 峰值 255 → 234.5（亮点软化）、能量 cv 0.38、闪烁 0.125 → 0.137。
- 断言口径：亚像素运动确实激发不稳定（plain flicker/cv 下限）、FXAA
  摊平边缘（分数覆盖增量）并软化无内部结构特征的峰值、时域闪烁保留
  在 plain 的 [0.3, 1.5] 倍区间（既未被消除也未加剧）。
- 运行日志 `out/validation/w15-aa-motion.log`。

## 遗漏的测试路径与永久检查

- 此前 FXAA 只有静态边缘质量断言（`fxaa_gpu.cpp`），没有运动下的
  时域量化——本次补齐为永久回归。
- 首版探针用总能量 cv 度量细线闪烁失败（长斜线阶梯平均化，cv 仅
  0.014）：细线的时域不稳定性体现在逐像素帧间差与边缘形状，总能量
  近似守恒；粒子类小特征才适合能量 cv。两种度量按场景固化。
- FXAA 沿边缘方向混合：有全亮核心的细线峰值不降，软化体现在分数
  覆盖；无内部结构的粒子峰值才下降。断言按此区分，避免把"软化"
  简化为单一峰值指标。
