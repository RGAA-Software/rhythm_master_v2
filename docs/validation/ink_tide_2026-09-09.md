# 墨潮功能交付

34 节点、46 连线的第一方二维音乐作品候选，1280×720。
纸色留白围绕墨绿流动区域，金色岸线、等高纹理与底部频谱带形成分层构图。
两个图像 Shader 分别控制颜料覆盖和岸线透明度，源码可在 Studio 修改、编译和发布。
空间噪声、位移、轮廓、遮罩和合成复用已有节点与已保留通知的 TiXL 适配器。

低频改变墨色覆盖，中频改变空间位移，高频推进等高线和金线；三个公开宏、
三套快照、四条 Cue、16 秒四片段配乐均可编辑。
音频复用光幕协奏的两份原创媒体；提取公共作者工具复用资产完整性检查，
重新生成瓷光钟摆的所有工程文件与先前字节完全相同。
来源与资产摘要见 `provenance/ink_tide.json`。

## 两端证据

- Windows 真实解码音乐与静音在相同 4 秒场景时间的平均 RGB 差 3.8745，
  80 Hz/静音 14.6680，3500 Hz/静音 2.4879，两音调间 14.7287；
  34 条指令均可达，稳定纹理 29,491,204 B。
- 实际 Studio 导出按钮完成 16 秒、480 帧 H.264 与非静音 PCM，时间戳正确；
  导出期间主图保持不变。成功文件位于
  `out/r6-ink-export/552400241326300/Exports/音画验收.mp4`。
- Android Redmi K40S / Adreno 650 的 GLES 非黑帧、设备重建和短测通过。
  Balanced 960×540，420 帧中后 300 帧同步 p50 17.85 ms、p95 20.00 ms，
  稳定纹理 16,588,804 B。未宣称 60 fps 或热稳定验收。
- APK 覆盖安装后，从竖屏目录搜索 `Ink Tide` 得到 1/42 条，选择“墨潮”后
  依据画布进入横屏，实际画面、16 秒配乐和非零 RMS 已查看。
- 缩略图来自真实 Player 渲染，最终包摘要与缩略图记录一致。
  已查看完整音乐截图与四个演出时段的导出画面，`visual-review-pending` 保持。
