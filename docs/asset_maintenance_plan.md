# R6 素材替换与修复

接续 R5 场景增量 `f97f7f7`。素材命令、后台检查/原文件恢复及 Studio 修复工程流程
已通过功能验证；证据与平台范围见 [短功能验证](validation/asset_maintenance_2026-09-09.md)。

## 功能合同

1. 素材列表显示类型、内容 ID、大小及未检查/正常/缺失/损坏状态；按需后台校验。
   复用单个 `Importer` 工作线程；一次检查最多 64 条记录、合计 1 GiB，支持取消。
2. 选择素材查看主图、组件定义、作品配乐和音频片段引用。
   “替换全部引用”为单次可撤销命令；只改类型化 AssetId，不按字符串搜索替换。
   去重已有相同素材，拒绝跨媒体族替换和同摘要元数据冲突；仍被引用的素材不能直接删除。
3. “用原文件修复”要求长度、SHA-256 和记录完全一致，复用 Store 的临时文件、
   哈希复核与原子替换。错误文件、取消、校验失败不得覆盖目标；完好副本保持不变。
   此操作修复内容存储，不是修改图参数，不伪装成可撤销的内容损坏。
4. Studio 可明确选择带素材警告打开工程，保留其图和记录供修复；
   普通严格加载、保存、发布及 Player 保留原来的完整性拒绝。
   缺失/损坏配乐不能借此绕过校验自动播放。恢复后重新准备资源，替换失败保留旧输出。
5. 图像、视频和 GLB 可在素材面板替换；音乐编排、Shader 编译继续使用专属创作入口。
   当前可修复其原始文件；不新增媒体解码后端或把素材 ID 改成机器路径。

## 复用

已检查本地 TiXL 的 `AssetLibrary.RelinkFolder.cs` 与 `FileAssetsHelper.cs` 中
路径重连校验、缺失状态、引用列表和批量更新使用者行为。
本项目使用不可变内容地址，故复用自己的 Store、Importer、编辑历史及类型化图遍历，
不移植可变路径挂载或 C#/DirectX 宿主。固定 revision/许可/文件 SHA 见
`provenance/asset_maintenance.json`；本增量未导入第三方源码。

## 验证顺序

- 纯命令：主图/组件/配乐片段、去重、错误媒体族、删除保护、undo/redo。
- 存储：正确原文件、同大小错误内容、缺失、损坏、取消、重复恢复与工作线程复用。
- Studio：鼠标/键盘输入、引用定位信息、替换、检查/恢复以及缺失工程打开后修复。
- 修复后保存/重开/发布/Player；共享核心 Android 原生回归，APK 继续覆盖安装。
- 长稳与最终作品品质验收仍最后进行。完成这一功能批后继续浏览、帮助、预览调度、
  40 语义组件/120 视觉独立预设及基础 50 + 高级 50 作品生产。
