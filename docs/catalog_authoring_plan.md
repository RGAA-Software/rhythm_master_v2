# R6 组件浏览与节点帮助

接续素材维护 `3fe378f`。中英文真实 GPU 界面测试与原模板浏览回归已通过。

## 使用流程

组件库按主题分组，搜索覆盖中英文名称和描述。选择条目先播放当前组件的真实运行包，
展示说明、连接类型和公开参数；按“插入组件”才产生一次可撤销编辑。
组件内部图仍可打开编辑，预览不是不可编辑的视频替代品。

模板库和组件库复用一个预览组件：每个窗口最多一个后台加载请求、一个 Player 会话，
预览为 256×144 内等比尺寸，使用当前音频特征。切换或关闭取消请求并丢弃迟到结果；
关闭释放 GPU 状态，预算失败停止重试，用户可显式重试。
加载器按需创建，准备结果返回后释放线程池；播放预览不占后台线程池名额。
关闭时取消尚未完成的加载，后续 UI 帧回收完成结果，避免把文件 I/O 等待放到鼠标操作中。
组件预览包由现有 Python 发布工具生成，独立于完整作品目录，不增加 Android 效果列表中的重复项。

原生节点列表悬停显示用途与连接指引；属性面板的“节点帮助”显示完整接口及默认值/范围。
这些类型、必需输入和参数边界来自图注册表，与编译校验使用同一合同。
中英文离线指引解释如何把标量、信号、纹理、点集、路径、几何、材质、场景、
相机、捕获和深度接到后续操作。通用类型指引不等于每个节点都已有专项教程。

关闭后无预览 pass 且纹理回到基线，以及原模板搜索/预览和 Studio 修复流程回归。
作品数量、独立视觉预设和用户品质验收仍单独记录。
