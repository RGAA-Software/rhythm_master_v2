# 材质贴图与局部灯光（R3 实施中）

本页记录已实现的契约；基础阴影另见 [阴影流程](shadow_pipeline.md)。
IBL 和 GLB 内嵌纹理导入仍在推进。

## 图内材质

`material.textures` 输入现有材质，按需绑定基础颜色、法线、ORM 和自发光纹理。
输入可以来自 `texture.image`、视频或程序生成节点；原有图资产扫描、保存、发布
路径继续包含这些依赖。未连接的槽继承输入材质，先前没有绑定时保持数值材质。
Scene3D 只保存纹理生产节点的稳定 ID；Runtime 用当前帧结果解析为 Renderer 句柄。
材质输入纹理固定保留到帧结果之后，避免在后续场景绘制或节点预览之前被纹理池复用。

颜色与自发光默认将解预乘后的 RGB 从 sRGB 转成线性；已线性化输入关闭该开关。
法线和 ORM 是原始数据，不做颜色转换。ORM 的 G 为粗糙度乘子、B 为金属度乘子；
R 为环境遮蔽，接入 IBL 时使用，不把遮蔽乘到直接灯光上。
当前贴图不改变材质覆盖率，覆盖率由数值材质的 alpha 决定；贴图 alpha 遮罩/透明待扩展。
UV 为左上原点，支持缩放/偏移，双线性重复寻址；没有隐式镜像或 V 翻转。

## 法线与切线

法线采用 RGB 切线空间、+Y 绿色方向。`normal_scale` 缩放 XY，随后规范化结果。
模型已有合法切线时保留；需要法线贴图而没有切线时，私有上传适配器调用 vcpkg
MikkTSpace。每个角的切线按原顶点 ID 与实际切线合并；镜像 UV 不覆盖共享顶点的
不同朝向。增加顶点后重新检查每模型 250,000 顶点预算，失败不发布半个网格。
不使用法线贴图的旧模型不强制生成切线。带切线和普通上传分别缓存，移除需求后释放。

顶点法线采用逆转置矩阵，切线按模型变换重新正交化，镜像模型的行列式修正手性。
插值 TBN 保持 MikkTSpace/Godot 的方向语义。实际检查覆盖非均匀缩放和镜像。

## 点光与聚光

`scene.point_light` 和 `scene.spot_light` 与方向光共用四灯预算。能量和位置可连信号；
聚光半角也可连信号。默认距离衰减为平方反比，并有平滑作用范围边界。
场景变换移动位置、旋转光轴；作用范围保持世界单位，不随几何缩放隐式改变。
聚光方向指向场景，方向光向量从表面指向光，二者方向约定不同。
灯光节点可预览，合并预算、图发布与播放参数保留均有检查。

## 当前短验证

- Windows D3D11 与 USB Adreno 650 / GLES 3.1：sRGB/线性颜色采样、UV 象限朝向、
  切线法线响应、镜像非均匀变换、ORM 金属度、自发光转换通过。
- Windows 与 USB Android：MikkTSpace 基础几何、镜像 UV 接缝、异常输入原子拒绝通过。
- Null 契约：跨设备、失效代次、深度误绑和同目标读写拒绝；采样后禁止同帧上传覆盖。
- Runtime：动态图材质输入保留、场景捕获、材质/场景节点预览和资源释放通过。
- 音律珐琅作品的真实音乐、确定性 MP4 导出、Android 覆盖安装与内置选择通过。
