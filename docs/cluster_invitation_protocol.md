# 房间邀请与成员权限 v1

实现位于 `src/cluster_auth`，当前仍由安全专项独立构建；不代表 App 已有扫码/联机入口。
密码后端来源与验证见 [身份专项](validation/room_identity_2026-09-07.md)。

## 邀请链接

固定前缀 `rhythmmaster://join/1/`，后跟 140 字节的无 padding base64url，共 209 字符。
不用 URL 查询参数、DNS、userinfo、百分号转义或重定向；整条链接含秘密，不能写日志。
下面是字段偏移，所有整数均为大端：

| 偏移 | 字节数 | 内容 |
| --- | --- | --- |
| 0 | 1 | schema = 1 |
| 1 | 1 | 地址族 = 4 或 6 |
| 2 | 2 | 非零端口 |
| 4 | 8 | 非零房间 epoch |
| 12 | 8 | 非零邀请 generation |
| 20 | 8 | Host 单调时钟下的过期微秒，范围 (0, 2^52] |
| 28 | 16 | IPv4 前四字节、其余零；或完整 IPv6 |
| 44 | 32 | 随机房间标识 |
| 76 | 32 | 随机邀请秘密 |
| 108 | 32 | 服务端完整 DER 证书的 SHA-256 |

参与者不能把 Host 的单调过期时间和本机时钟直接比较；加入时由 Host 作权威校验。
证书有效期另按本机日历时间验证，设备时钟错误需要清晰诊断。
未知版本、非法 alphabet、未使用尾随位非零、截断/附加字节、空凭据和无效端点拒绝。
IPv4 排除 0/8、组播/保留高段，IPv6 排除未指定、组播、link-local 和 IPv4-mapped。
依赖 scope 的 IPv6 link-local 不能靠本机接口编号在另一台手机上解析，本版不编码它。
Host 网卡选择/可达性和后续 scoped endpoint 模式仍属平台适配任务。

## 房间权限状态

RoomAuthority 由房间所有者串行调用；无 socket、QUIC、UI 或 runtime 后端类型。
仅在 TLS 完成后处理加入。连接 ID 由本地传输适配器产生、非零且不复用，绝不能信任
网络中的同名字段。传输每连接只允许一个加入请求正在执行，并先关闭传输再通知断开。

- 邀请最多有效 10 分钟、最多 1000 次成功加入；重新签发递增 generation 并撤销旧秘密。
- 成员默认上限 100，可配置 1..1000；离线但未过期成员保留位置，过期/踢人释放。
- 加入协商 profile 位集；不兼容加入不消耗邀请次数。每个成功成员获得独立 256 位凭据。
- 锁房拒绝新成员；已加入成员可在断开后用现存凭据重连。重连立即轮换凭据，旧凭据失效。
- 会话凭据有效 30 分钟，连接内可续期（最多每分钟一次）；续期轮换凭据并延长租期。
  断线重连本身不延长租期；过期必须凭有效邀请重新加入。
- 每成员控制序列严格递增，绑定成员、当前连接和 epoch；重连/续期不清除重放水位。
- 加入/重连共享有限令牌桶：突发 20 次、每秒恢复 5 次，失败尝试也计数。
  这是目前保守策略，尚须与原生握手上限、IP/连接限流和现场加入速度共同验证。
- 撤销邀请不踢出现有成员；Kick 立即撤销成员权限；End 清空并永久关闭当前 authority。
- 这只授予参与播放的身份，不授予远程编辑、命令执行、资源上传或管理权限。具体消息
  白名单和资源下载授权由消息处理层在该身份之上执行。

过期清理只在最早租期到达时扫描成员，不为每条已认证控制消息扫描整个房间。
还需由宿主调用 Tick，并同步关闭被踢出/过期成员的传输、取消资源下载和场景成员资格。
暂不宣称无响应客户端、重连风暴或 1000 人现场容量已通过。

## 可靠通道上的加入消息

Admission codec 使用 8 字节头：`RMAD`、version=1、kind、完整消息长度 u16。
整数大端，固定长度，拒绝未知版本/类型、错误长度和额外字节；外层由 StreamDecoder
添加四字节长度帧。Join=100 字节（epoch/generation/expiry/room/secret/profiles）；
Welcome=76 字节（peer/epoch/credential/profiles/expiry/control watermark）；
Resume=56 字节（peer/epoch/credential）；Refresh=32 字节（peer/epoch/sequence）；
Rejected=9 字节，原因 1..5 对应 invalid/locked/capacity/rate limited/incompatible。

AdmissionGate 绑定一条本地 TLS 连接：加入前仅接受 Join/Resume，五秒未认证关闭；
加入后拒绝重复 Join、错误方向消息、旧 epoch 和重放。续期太频繁可回复限流并保留连接；
授权失败或租期到达则关闭。传输真正关闭后必须通知 authority 解除绑定。
身份只允许后续参与者白名单处理，不能据此执行管理命令。

Windows 与 USB Android 的真实加密双向 stream 已完成 Join/Welcome/Refresh，
正确凭据续期，错误秘密/已撤销邀请拒绝，重放触发关闭并解除绑定。每次测试使用新生成
身份，Windows 先执行 DPAPI 保存/恢复。该测试以模拟的 Host 时间验证续期，
不把快速执行误报为真实运行了三小时；尚未接入资源/场景同步和 App 界面。
