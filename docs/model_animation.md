# 模型动画与姿态

2026-09-08，R4 持续开发。已实现 GLB 节点 TRS 动画、关键帧采样、两段动画混合、
统一时间、节点预览与共享静态上传。骨架蒙皮和 morph 顶点渲染继续开发；当前权重
采样契约通过测试，不表示 morph 已能显示。R4–R6 尚未全部完成。

## 创作流程

导入含动画的 GLB，连接 `geometry.glb → geometry.animate → scene.instance`。
主动画和混合动画可按名称选择；资产尚未准备好或经组件转接时显示片段编号。
混合比例可以连接音乐信号。未接时间输入时使用作品统一时间；显式时间输入支持
局部时间、曲线和其他信号。速度范围 -16..16，偏移 ±86400 秒，支持循环或端点保持。
两段动画使用同一秒数，各自按片段长度循环；不是归一化相位同步。

更换片段与参数沿用属性事务、撤销/重做、保存和运行包属性。现阶段导入动画资源
通过原 GLB 随包保存，两端均从同一资源读取，不另建媒体或动画时钟。

## 契约和预算

- `AnimationClip` 构造时验证，发布后只提供只读轨道；每次采样对时间二分定位。
- 支持 STEP、LINEAR、CUBICSPLINE。旋转线性使用最短弧 slerp；三次使用分量
  Hermite，按相邻时间差缩放切线，然后归一化。三次旋转不做符号半球修正。
- 时间必须非负、严格递增、有限，最长 24 小时；单帧片段有效。循环支持负时间。
  缺失通道保持模型默认 TRS；不同片段混合时也以同一默认姿态补齐。
- 每模型最多 64 片段、8192 通道、262144 个四分量值（含三次切线），姿态最多
  2048 节点。图最多 32 个动画求值节点，场景姿态层级缓存最多 65536 节点。
- 当前 glTF 通道只开放平移、旋转、缩放；矩阵节点不接受动画通道，稀疏访问器和
  压缩动画不在当前范围。零长度四元数、非有限结果、接近零的缩放拒绝。
- `Geometry` 共享不可变 `Model` 和基础上传 ID，另持有小型不可变姿态。
  动画/原始实例共用网格和内嵌图像上传；每实例层级姿态分别生成绘制矩阵。
  时间不变时保持快照，显式时间输入不会被自动时钟反复失效。

Hermite 后归一化规则，数值测试特意检查了有非零切线的差异。
