# Android 内置作品检索

接续 `b850cf4`，Player 的效果选择与演出队列添加共用同一个原生目录。
搜索匹配中英文名称、说明及作品 ID，大小写无关，多个词需同时匹配；
级别与画布方向筛选同时生效。条目显示原生缩略图、级别、方向、音乐驱动提示和说明。
无匹配结果时展示明确提示与数量，选择使用过滤后的作品身份，不使用原目录行号。

目录为 APK 内置数据，不读取用户文件目录、不访问网络、不启动新渲染或解码服务。
`EffectCatalog` 负责后台载入与不可修改条目列表；`EffectPicker` 负责主线程 UI 和过滤结果。
复用 Android 的 SearchView、Spinner、ListView、BaseAdapter 与 AlertDialog，
没有导入额外 UI 库或第三方代码。窗口按当前可用区域定尺寸，筛选不改变窗口大小；
横屏搜索禁用全屏输入框，提交后收起键盘。真正的播放方向仍由所选作品画布决定。

Python APK 打包携带双语说明和既有 tier 字段，校验器检查必要字段、包摘要、画布与缩略图。
仍使用同一条增量构建和 `adb install -r`，保留已有工程和播放数据。
