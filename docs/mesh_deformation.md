# R4 GPU 网格变形

`geometry.deform` 将 Geometry 接入有序的 GPU 扭转/收缩处理，再输出 Geometry，
继续使用已有实例、材质、场景、节点预览和发布流程。半径变化的路径生成仍走
[路径几何](path_geometry.md)；这里的变形参数变化不会重新生成 CPU 顶点数组。

## 语义和边界

- 扭转以“度 / 局部单位”表示，可连音乐或时间，范围 ±720；收缩系数范围 ±4。
  X/Y/Z 轴可选，枢轴范围 ±10000；收缩与扭转使用同一枢轴。
- 沿选定轴的位置决定扭转角度及截面缩放，遵循右手旋转。截面缩放
  `1 - taper * along` 限制在 0.05–20，防止反转、零面积截面和不可逆法线变换。
- 一个节点先收缩再扭转，最多串联四个节点；串联顺序就是执行顺序。
  在模型层级与场景实例变换之前、每个网格的局部坐标中执行。
- 法线使用解析逆转置，切线使用位置变换的 Jacobian，保留 UV 和切线手性。
  对已触及收缩上下界的顶点，缩放导数取零；极端参数可能形成明显折痕。
- 同一基础模型的原始、不同变形实例共享不可变 CPU 模型、内嵌图片和 GPU 上传。
  节点输出版本与基础上传版本分别记录；只有基础几何本身变化才重建上传。
  相同变形参数的实例可以批量绘制；参数不同的实例分开提交。
- 投影使用与颜色绘制相同的顶点变形；法线贴图、环境反射和普通灯光继续可用。
  预览有独立、可释放的上传缓存。无新增原生图形类型进入 graph/runtime API。

这是有界顶点修改器，尚非任意网格拓扑编辑、蒙皮、morph 或通用 compute 节点。
变形后的顶点只在 GPU 绘制时存在，当前不导出为烘焙 GLB；运行包和视频保留效果。
原网格细分不足会出现折线，需要提高基础几何细分；不会隐式增加顶点数。

## 复用

在现有 Godot 参考材质/场景管线内，扭转和收缩参考 TiXL `mesh-Deform.hlsl`。
保留固定源文件及 MIT 通知，记录于 [出处](../provenance/mesh_deformation.json)。
移除其 D3D compute 缓冲、选择权重和球化；统一右手轴约定，新增收缩边界和四层限制。
上游直接沿用原法线/切线，这里改为与实际变形一致的变换，以保持纹理光照正确。
独立 GPU 检查使用已有 vcpkg GLM 旋转和有限差分，不新增依赖。
