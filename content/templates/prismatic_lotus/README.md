# 棱镜星莲 / Prismatic lotus

Advanced reference candidate; user visual acceptance is pending. This is one
composition, not a collection of color variants counted as separate templates.

Two independently evolving grayscale fractal fields pass through polar remapping,
mirrored sectors and luminance contours. The cool outer filaments and warm inner
spiral counter-rotate, with a soft circular aperture, near/far glow and quiet dust.
Audio RMS adds a restrained breathing motion. Silence retains the entire moving
composition. All imagery is generated by the normal editable graph; no pre-rendered
video or template-specific renderer branch is involved.

## Editing / 编辑

Open the template **棱镜星莲 / Prismatic lotus** in Studio. The root contains seven
nodes; enter the central component to edit its 24 nodes. The separate dust and
five-node glow components remain editable and expose their normal controls.

- 运动速度 / Motion speed: speed of the primary evolving field; rotation speed
  separately controls the cool layer. Negative inner rotation loops over 360°.
- 镜像扇区 / Mirror sectors: primary fold count; default 10. The warm layer has its
  own count inside the component, so deliberate asymmetry can be authored.
- 等高线数量 / Contour count and line width: detail density and highlight coverage.
  More detail is not automatically better. Coarse scalar-field smoothing precedes
  contour extraction to reduce unresolved central texture detail.
- 扭曲 / Twist: polar spiral curvature. Warm filaments adjusts the second layer.
- Color A/B and near/wide glow: control the cool palette and the shared halo.

The clock remains bounded for the noise phases, radial travel and both rotations.
The preview's six seconds are a sample of continuous evolution, not a claimed
seamless six-second loop. Captured audio features are explicitly synthetic; a
separate silent preview verifies idle motion. No local audio-file decoding claim
is made by this template.

## Profiles and sources

Authored canvas: 1280×720. Windows D3D11 is the current review profile. The shared
GLES shader build is also checked, but Android device visual/performance acceptance
is pending. RGBA8 glow is composited in bounded render targets, not HDR bloom.

TiXL MIT polar/noise/blur adaptations and Material Maker MIT sector replication
are recorded in `provenance/tixl_effects.json` and
`provenance/material_maker_effects.json`. The graph and contour coverage adapter
are project-owned. Exact upstream notices are included in the application deploy.
The repository's outbound license is still undecided.
